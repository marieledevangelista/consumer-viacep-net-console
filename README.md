# ConsumerViaCep

Aplicação console em C# que consulta um CEP utilizando a API ViaCEP.

O programa solicita um CEP ao usuário, faz uma requisição para o endpoint da ViaCEP e exibe alguns dados do endereço retornado, como CEP, rua, bairro, cidade e UF.

Endpoint utilizado:

`https://viacep.com.br/ws/{cep}/json/`
